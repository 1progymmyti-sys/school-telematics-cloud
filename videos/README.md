# Φάκελος βίντεο

Βάλτε εδώ τα αρχεία βίντεο (MP4) που θέλετε να προβάλλονται στις οθόνες.

1. Στο GitHub ανοίξτε αυτόν τον φάκελο (`videos`) και πατήστε **Add file → Upload files**.
2. Σύρετε το βίντεο και πατήστε **Commit changes**.
3. Στη σελίδα διαχείρισης επιλέξτε τύπο **🎬 Βίντεο** και γράψτε μόνο το όνομα του αρχείου (π.χ. `giorti.mp4`).

Συμβουλές:
- Μορφή **MP4** (H.264), μέγεθος έως **25 MB** (όριο του GitHub για ανέβασμα από τον browser).
- Ανάλυση 720p ή 1080p είναι αρκετή. Για μικρότερο αρχείο χρησιμοποιήστε το δωρεάν HandBrake.
- Το όνομα πρέπει να είναι **ακριβώς ίδιο** (κεφαλαία/μικρά). Προτιμήστε λατινικούς χαρακτήρες χωρίς κενά, π.χ. `ekdilosi-28is.mp4`.
